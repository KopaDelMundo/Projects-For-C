# Week 1 - Damage Calculator
    A small terminal program from my C learning roadmap. Simulates combat
    damage using attack/defense stats, random variance, elemental
    multipliers, and critical hits.

## Build
    clang -Wall -Wextra -g -o main main.c

## Run
    ./main

##sample output

    Hero gets ready to attack!
    Base damage is 230
    Percent modifier is 4
    4 percent of 230 is 9.000000
    damage percent is positive
    The resulting attack damage is  239
    Elemental disadvantage! Damage reduced.
    Hero attacks Villian for 139
